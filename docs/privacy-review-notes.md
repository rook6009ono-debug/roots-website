# privacy.html（個人情報保護方針）確認メモ

## 重要: 本ページはドラフトです

[privacy.html](../privacy.html) は、訪問看護事業者向けの一般的な構成で作成した
**お客様確認用のドラフトであり、法的に確定した文書ではありません**。
公開前に必ず運営会社（株式会社gravity）にて内容の確認・承認を受けてください。
必要に応じて弁護士・行政書士等の専門家によるリーガルチェックを推奨します。

## ドラフトの構成（ご指定の項目に対応）

1. 個人情報の取得について
2. 利用目的
3. 第三者への提供
4. 業務委託について
5. 安全管理措置
6. 開示・訂正・利用停止等のご請求
7. Cookie・アクセス解析について
8. お問い合わせ窓口（company.json から自動表示）
9. 本方針の変更

※現行サイトのお問い合わせページに掲載されている「個人情報の取扱いについて」の記述内容を踏まえて作成しています。

## 公開前にお客様に確認・決定していただく事項

- [ ] 各条文の内容が実際の運用と合っているか（特に「2. 利用目的」「3. 第三者への提供」「4. 業務委託」）
- [ ] 訪問看護事業特有の記載の要否（医療・介護関係事業者における個人情報の適切な取扱いのためのガイダンスへの言及、利用者情報の院内掲示・同意書との整合など）
- [ ] 制定日（現在は空欄「＿＿＿＿年＿＿月＿＿日」）
- [ ] 責任者の表記（現在は「代表取締役　荘　徹男」）
- [ ] Cookie/アクセス解析の記載（GA4を実際に導入するかどうかに合わせて調整）
- [ ] 確認完了後、ページ冒頭の**オレンジ色の「ドラフト」注意書きを削除**する
  - privacy.html 内の `<p class="privacy-draft-note">…</p>` の1行を削除するだけ

## 技術メモ

- 会社名・住所・電話番号・代表者名は `data/company.json` から `js/render-privacy.js` が自動反映
  （`<span data-company="キー名">` の中身を差し替える方式。JS無効時もHTML直書きの値が表示される）
- フッターの全ページ共通ナビに「個人情報保護方針」リンクを追加済み（js/include.js）
- お問い合わせフォームの同意チェックとフォーム内の2箇所から privacy.html へリンク済み
