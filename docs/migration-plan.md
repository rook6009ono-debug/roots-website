# gravity2018.co.jp 移管計画書（レンタルサーバー方式）

作成: 2026-07-28
方針: 新規にレンタルサーバーを契約し、ドメイン gravity2018.co.jp を現制作会社の管理から切り替えて公開する。

## 全体の流れ

```
STEP1 現制作会社へ確認 (返信待ちの件)   ← 今ここ
STEP2 レンタルサーバー契約 (お客様名義推奨)
STEP3 事前準備 (メールアカウント作成 / GASフォーム接続 / 動作確認)
STEP4 ドメイン切替 (ネームサーバー変更)  ← サイトとメールが新サーバーに向く
STEP5 公開後作業 (SSL確認 / Search Console / 旧契約解約)
```

---

## STEP1: 現制作会社への確認事項（このまま送れる質問リスト）

> 1. ドメイン「gravity2018.co.jp」はどちらの事業者（レジストラ）で管理されていますか？
>    ドメインの管理を当方（または貴社経由でお客様）へ移す場合の手続きを教えてください。
>    （ドメイン移管の場合: AuthCode（認証コード）の発行と、移管ロック解除をお願いします）
> 2. ドメインだけ継続管理いただき、ネームサーバー（DNS）の変更のみ対応いただくことは可能ですか？
> 3. 現在 @gravity2018.co.jp のメールアドレスは運用されていますか？
>    運用中の場合、メールアカウントの一覧（アドレスのみで可）を教えてください。
> 4. 現在のDNSレコード一覧（特にMX・TXT/SPF・DKIM）を共有いただけますか？
> 5. 現サーバー・CMSの契約解約はいつ付けで可能ですか？ 解約希望の連絡はいつまでに必要ですか？
> 6. 切替完了まで現サイトはそのまま公開を継続いただけますか？

**重要**: 3・4の回答が来るまでDNSは絶対に変更しない。メールが止まる事故を防ぐため。

## STEP2: レンタルサーバー契約

- 推奨: **エックスサーバー スタンダード**（月990円〜・無料SSL・メール無制限・10日間無料お試し）
  - 同等の代替: ロリポップ ハイスピード / さくらのレンタルサーバ スタンダード
- 契約名義は**お客様（株式会社gravity）推奨**（事業者依存を再び作らないため）。当方が代理設定する場合はサーバーパネルのログイン情報を共有してもらう
- 契約後、サーバーパネルで「ドメイン設定」に gravity2018.co.jp を追加（この時点ではDNSは旧のままでOK）

## STEP3: 事前準備（DNS切替の前に済ませる）

1. **メールアカウント作成**: STEP1-3で判明した全アドレスを新サーバーに同名で作成（パスワードはお客様に発行）
2. **サイトのアップロード**: `roots-website-release.zip`（本番用パッケージ・生成済み）を
   サーバーの公開ディレクトリ（Xserverなら `/gravity2018.co.jp/public_html/`）に展開
   - アップロードはサーバーパネルの「ファイルマネージャ」（zipのままアップロード→展開）が簡単
   - パッケージの再生成はローカルで `node tools/build-release.js`
3. **動作確認URL**: Xserverの「動作確認URL」機能で、DNS切替前に新サーバー上の表示を確認できる
4. **フォーム接続**: docs/contact-form-setup.md の手順でGASをデプロイし、
   `js/site-config.js` の contactEndpoint を設定 → release再生成 → 再アップロード
   - 通知先はお客様のメールアドレス（切替後は @gravity2018.co.jp も使用可）
5. **プライバシーポリシー仕上げ**: 制定日を記入し、ドラフト注意書き（オレンジ枠）を削除
6. **無料SSLの設定**: サーバーパネルでSSL設定（DNS切替後に有効化される。Xserverは切替後自動）

## STEP4: ドメイン切替（ネームサーバー変更）

パターンA（推奨・簡単）: **ドメイン管理は現状のまま、ネームサーバーだけ変更**
- 現制作会社（またはレジストラ管理画面）で、ネームサーバーをXserver指定
  （ns1.xserver.jp 〜 ns5.xserver.jp）に変更してもらう
- 浸透まで数時間〜最大72時間。旧サイトは浸透中も表示されるため実質ダウンタイムなし

パターンB: **ドメインごと移管**（お客様が完全に管理を取り戻したい場合）
- AuthCode取得 → Xserverドメイン等で移管申請 → 承認 → 移管完了後にネームサーバー設定
- .co.jpの移管は1〜2週間かかることがある。サイト公開を急ぐ場合はパターンAで先に切替え、移管は後日でもよい

**切替直前チェックリスト**
- [ ] 新サーバーにメールアカウント作成済み（STEP1-3の全アドレス）
- [ ] SPF等のTXTレコードを新DNSにも設定（Xserverは標準で自動設定。独自のSPF/DKIMがあった場合のみ手動追加）
- [ ] 動作確認URLで全ページ表示OK
- [ ] フォームのテスト送信OK（GAS接続済み）

## STEP5: 切替後の作業

- [ ] https://www.gravity2018.co.jp/ が新サイトで表示されることを確認（スマホ回線でも確認）
- [ ] SSL（https）有効・鍵マーク表示を確認。http→httpsのリダイレクト設定（Xserverは.htaccessで設定）
- [ ] wwwなし → wwwあり のリダイレクト設定
- [ ] メールの送受信テスト（全アカウント）
- [ ] Google Search Console にサイト登録 → sitemap.xml を送信
- [ ] GA4を発行して site-config.js に設定（任意）
- [ ] Googleビジネスプロフィール等の住所も新住所（玉川町2-9-7）に更新されているか確認
- [ ] 1〜2週間問題がないことを確認してから、現制作会社の契約を解約
  （解約前に旧CMS内に未取得のデータがないか最終確認）
